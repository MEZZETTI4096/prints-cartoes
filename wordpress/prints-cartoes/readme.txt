Página de Cartões de Visitas da Gráfica Print's com pedido pelo WhatsApp, editável pelo editor de blocos.

== Instalação ==

1. Painel do WordPress > Plugins > Adicionar novo > Enviar plugin > prints-cartoes.zip > Instalar > Ativar.
2. Pronto: ao ativar, o plugin cria a página "Cartões de Visitas" em /cartoes e coloca as imagens na Biblioteca de Mídia.
   (Se já existir uma página /cartoes, ela é mantida. Para substituí-la: Ferramentas > Prints Cartões > Recriar.)

== Editar ==

Páginas > Cartões de Visitas > Editar. Tudo é editável no editor de blocos:

* Títulos, textos e imagens: blocos nativos do WordPress (clique e edite; imagens: Substituir).
* Seção: agrupa título + imagem + descrição de um produto. Duplicar uma seção cria um novo produto.
* Lista de opções (preços): uma opção por linha; título; obrigatório; texto antes de escolher.
* Opções de marcar: uma opção por linha; título; obrigatório.
* Formulário de pedido: número do WhatsApp e texto do botão (barra lateral).

Os blocos ficam na categoria "Gráfica Print's" do inseridor (+), dentro do Formulário de pedido.

== Modelo de página ==

"Prints Cartões (página inteira)": idêntica à página original, sem cabeçalho/rodapé e sem o CSS do tema.
Sem esse modelo, o formulário aparece dentro do layout do tema.
